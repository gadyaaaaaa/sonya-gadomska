# Working instructions

- The repository owner is a lawyer, not a programmer. Keep explanations short and use plain language.
- Ask fewer questions; make reasonable choices within the requested scope.
- Commit completed changes directly to this GitHub repository when access permits.
- Keep changes narrow and reversible. Record the previous commit before significant changes and explain how to roll back.
- Preserve existing content and unrelated work.
- Never commit passwords, API keys, local environment files, or private personal documents.
- Verify changes with checks appropriate to the work and report any checks that could not run.
- Do not publish or deploy a website unless the user requests it.
