# Remainable implementation plan

© 2026 Sonya Gadomska. All rights reserved.

1. Phase 1: complete clickable local application, fictional sample, truthful documentation-only uploads, evidence viewer, versioned reports and browser PDF printing.
2. Phase 2: authenticated Supabase persistence/private storage, migrations and server-only per-image structured multimodal analysis. Validate all responses; provider stays replaceable.
3. Phase 3: building synthesis and site-specific missing-evidence workflow, distinct from professional conclusions.
4. Phase 4: selective reassessment, preserved observations and audited evidence/report versions.
5. Phase 5: professional review, mobile polish, production PDF export and deployment validation.

This delivery implements Phase 1 and a small provider/prompt boundary. It does not represent mock outputs as live AI results. Preview scaffolding for reports and revisions makes the full proposed flow testable before accounts and model integration.

Acceptance: landing → form → photos → demo screening → findings → follow-up uploads → versioned report. For real uploads, the result must remain unreviewed and must not assign an engineering conclusion or priority.
