# Remainable logo exports

- **remainable-profile.png** — 2048 × 2048, the website wordmark on its warm white background; use for LinkedIn or Facebook. Centered with room for a circular crop.
- **remainable-profile-icon.png** — 2048 × 2048, the existing website R favicon, with padding for a circular crop. Best when the profile image is displayed very small.
- **remainable-wordmark-transparent.png** — 4096 × 720, transparent background, for layouts and posts.
- Matching SVG files are scalable masters; all lettering is outlined, so no font installation is needed.

Source: https://remainable.ca/, live header, stylesheet and /icon.svg retrieved 2026-09-13. Original spelling, Arial Bold lettering, scan paths, spacing and brand colors retained. The square R version uses the existing favicon, not a new logo.
